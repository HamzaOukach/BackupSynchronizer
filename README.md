## 💾 BackupSynchronizer

A system that allows users to automatically back up files at configurable time intervals, with a graphical interface. Uses TCP/IP sockets for network communication and file transfer.

### Features
- Automatic file backup at scheduled intervals
- Graphical user interface for configuration and monitoring
- Network file transfer via TCP/IP sockets

### Tech Stack
- **Language:** Java
- **GUI:** Java Swing
- **Networking:** Java Sockets (`java.net`)
- **File I/O:** `java.io`

### Getting Started

**Prerequisites:**
- Java JDK installed

**Run the project:**

1. Clone the repository to your local machine
2. Compile and run (adjust paths/class names as needed):
 `javac -d bin src/*.java`
 `java -cp bin MainClassName`
